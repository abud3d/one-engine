# المشكلات والحدود المعروفة

لا توجد مشكلة حرجة معروفة في التدفق المختبر الحالي.

## ب — عوائق وظيفية

- لا يوجد سجل تدقيق دائم أو allowlist مهيأ لترويسة `Origin`. تعتمد معاينة التطوير على CSRF وSameSite=Strict؛ لذلك لا تُعامل كتهيئة نشر إنتاجي قبل إضافة الضابطين.

## ج — تحسينات

- مكتبة الوسائط تدير صور HTTPS وتتيح اختيارها في البلوكات. رفع الملفات الثنائية مؤجل حتى تتوفر معالجة MIME وتخزين وحصص واختبارات تصدير تمنع الملفات الخبيثة.
- إنشاء ZIP يحتاج امتداد PHP `zip`. يبقى تصدير الدليل المستقل عاملًا بدونه، ويعرض الأمر سبب التعذر بوضوح.

## بيئة التسليم

- رفعت GitHub Actions حزم ZIP بنجاح، لكن تنزيل artifact إلى بيئة Codex أعاد HTTP 403 من مخزن GitHub الخارجي بعد محاولة واحدة. تبقى الحزمة متاحة من صفحة تشغيل Actions للمستخدم المخول؛ لم يؤثر ذلك في بنائها أو فحص الوظائف داخل workflow.
